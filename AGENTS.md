# William’s Pizza 2026

## Project direction

- Keep the experience editorial, warm, modern, and conversion-focused.
- Use the red, cream, charcoal, and white brand system already defined in `src/app/globals.css`.
- Preserve Portuguese copy and the real Gramado + Canela delivery context.
- Keep motion subtle and purposeful. Respect `prefers-reduced-motion`.
- Keep all reusable content in `src/lib/site-content.ts` and all sections composable through `src/components/site-page.tsx`.

## Verification

Run `npm run lint`, `npm run typecheck`, and `npm run build` before publishing.
